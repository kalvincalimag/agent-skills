# Examples by technique

Load this at step 3 when a technique needs a model, or to explain a finalist by comparison. Origins are given only where they are well documented. Elsewhere the right-hand column analyzes the name, not its history.

## Metaphor

| Name | Product | Why it works |
| --- | --- | --- |
| Docker | containers | A docker loads and unloads ship cargo. The whole vocabulary of images, containers, and registries follows the metaphor. |
| Terraform | infrastructure as code | Shaping barren land into habitable ground, as code shapes servers. Three syllables, but the image is vivid enough to carry them. |
| Helm | Kubernetes package manager | Where you steer a ship, and "Kubernetes" is Greek for helmsman, so the family shares a territory. One syllable. |
| Vault | secrets storage | So direct it is nearly literal, and that is the strength. One syllable. |

## Repurposed common word

| Name | Product | Why it works |
| --- | --- | --- |
| Slack | team chat | The word means ease and looseness. The official expansion, "searchable log of all conversation and knowledge", came after the name. |
| Stripe | payments | One syllable, the sharp str- cluster, and a visual word. |
| Linear | issue tracking | The dictionary meaning is the brand promise: straight, direct, uncluttered. |
| Notion | notes and docs | A notion is an idea. Soft sounds suit a flexible tool. |

## Compound

| Name | Product | Why it works |
| --- | --- | --- |
| PagerDuty | incident response | Named after the on-call experience of its own users. Both halves are concrete. |
| Datadog | monitoring | Taken from a database server at the founders' previous company. "Dog" adds a watchdog's personality. |
| Mailchimp | email marketing | The unexpected chimp warms a dry category. |
| Bluetooth | wireless standard | Named after a tenth-century Danish king who united warring factions, as the standard unites devices. |

## Invented with a root

| Name | Product | Why it works |
| --- | --- | --- |
| Figma | design tool | Five letters, easy to say worldwide, with "figure" audible inside. |
| Deno | JavaScript runtime | "Node" rearranged. The link to its predecessor rewards those who notice, and the name stands alone. |
| Redis | in-memory database | An acronym, remote dictionary server, that happens to read as a short, distinct word. Acronyms rarely do. |

## Borrowed word or cultural reference

| Name | Product | Why it works |
| --- | --- | --- |
| Kafka | event streaming | Named after the writer. Its creator called it a system optimized for writing. |
| Ansible | configuration tool | Ursula K. Le Guin's device for instant communication across any distance, applied to any number of servers. |
| Jira | issue tracking | Shortened from Gojira, Japanese for Godzilla, as a nod to the Bugzilla tracker its makers used. |
| Vite, Svelte | web tooling | French for "fast", and the word for "slender". Each states the tool's idea in one syllable. |
| Rust | programming language | Named after rust fungi, which are hardy and persistent. One syllable, easy to type. |

## Names that teach by failing

| Name | What goes wrong |
| --- | --- |
| CloudWatch | Filler plus a generic verb. It blurs with CloudMonitor, CloudGuard, and CloudSentry in memory. |
| Site24x7 | A description formatted as a name. The numbers add load and no image. |
| ZEIT | German for "time". Hard to spell and say across languages, so the company renamed itself Vercel in 2020. |

## Patterns

- Most of these are one or two syllables.
- Each has a story that takes seconds to tell.
- Specific beats general. Sentry beats Guard. Docker beats Container.
- Sound matches character: hard consonants for infrastructure (Docker, Kafka, Vault), softer sounds for consumer tools (Notion).
- The best compounds surprise. Mail plus chimp works. Cloud plus watch does not.
- Several came from inside the team: a codename, an in-joke, or the users' own jargon. Ask the user for their codenames and jargon in the brief.
