# Taglines

Load this at step 8 to write one or two taglines per finalist. A name and its tagline work as a pair. The name supplies the image and the recall. The tagline answers the question the name leaves open: what does this actually do?

| Name supplies | Tagline supplies |
| --- | --- |
| image | category and job |
| character and tone | audience and use |
| recall | clarity |

Read each alone. Each should make sense on its own, and together they should say more than either does alone.

## Forms that work

- **"[Category] for [audience]."** The simplest and most reliable. Use it when the name is abstract and needs grounding. "Payment infrastructure for the internet."
- **"[Verb] your [noun]."** Use it when the main action is the selling point. "Plan your week's meals."
- **"The [adjective] way to [action]."** Use it when the difference is speed or simplicity, and name what makes it so. "Simple" and "modern" alone say nothing.
- **Three verbs.** Use it when the value is a short workflow. "Develop. Preview. Ship."
- **One plain statement.** Use it when the brand's character is calm confidence. "Your connected workspace."

## Failures

- **Too long.** Over ten words, it is a description, not a tagline.
- **Generic.** If a competitor's name fits in front of it, it says nothing: "Solutions for modern teams", "Built for the future".
- **Repeats the name.** "Sentry: watching over your code" adds nothing that "Sentry" did not say. "Sentry: application monitoring for developers" adds the category and the audience.
- **Buzzword stack.** "AI-powered, cloud-native solutions for digital transformation." Pick one concrete thing the product does and say it.

## The billboard test

Read the name and tagline as if passing them on a billboard at highway speed, with about three seconds. Can you read all of it, understand what the product does, and still remember it ten minutes later? If not, shorten it or make it concrete.

A tagline is not a slogan. A slogan belongs to one campaign and changes. A tagline sits beside the name for years.
